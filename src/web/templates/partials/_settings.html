Fungsi: Entitas atau data rahasia warga/instansi (contoh: ktp, nik, kartu keluarga, npwp, data nasabah, bpjs). Kata ini TIDAK berdiri sendiri—hanya memicu status relevan jika ditemukan BERSAMAAN dengan indikator aksi (misal: KTP + bocor atau NIK + dijual).
Fungsi: Infrastruktur sistem, aplikasi, dan jaringan instansi (contoh: website, server, database, aplikasi, rekening, pdns). Wajib berpasangan dengan kata aksi insiden (misal: server + dibobol atau website + diretas) agar artikel peluncuran sistem publik normal tidak salah terjaring.
