settings Pengaturan Sistem CTI Diskominfo Jatim

Manajemen LLM Gemini, Kata Kunci Scraping, Template Prompt Intelijen, Sumber Feed RSS, dan Referensi CTI.

memory Kredensial Google Gemini API

Sistem mendeteksi ambang batas proaktif (90%-95% RPM). Model embedding otomatis berganti pada 90 RPM (kuota 100 RPM), dan 7 model narasi berganti sebelum menyentuh batas limit. Jika seluruh model pada satu kunci jenuh, sistem beralih ke kunci berikutnya.

alt_route Rantai Model Narasi & Failover

Model pertama dicoba lebih dulu. Jika kuota habis atau batas rate limit tercapai, otomatis berpindah ke model cadangan berikutnya: gemini-2.5-flash (5 RPM), gemini-2.5-flash-lite (10 RPM), gemini-3-flash (5 RPM), gemini-3.1-flash-lite (15 RPM), gemini-3.6-flash (5 RPM), gemini-3.5-flash-lite (15 RPM), gemini-3.8-flash (5 RPM).

Inferensi Deterministik Terkunci: Parameter temperature inferensi diatur tetap secara presisi pada 0.1 untuk menjamin akurasi dan kepatuhan penuh pada fakta berita tanpa halusinasi.

manage_search Filter Kata Kunci Scraping & Klasifikasi Relevansi

Kelola kamus kata kunci penyaring berita siber secara visual melalui sub-tab kategori. Tanpa penulisan koma manual, dengan tombol tambah, hapus konfirmasi, dan simpan permanen.

Indikator Insiden Mandiri (Bahasa Indonesia)

Fungsi Taktis: Kata kunci berkekuatan mandiri yang pasti menandakan insiden siber (contoh: kebocoran data, ransomware, phishing, peretasan, situs diretas). Jika artikel memuat salah satu kata ini, artikel otomatis dinyatakan relevan tanpa perlu kata pelengkap.

Belum ada kata kunci mandiri terdaftar.

Objek Data Sensitif (Butuh Indikator Aksi)

Fungsi Taktis: Entitas atau data rahasia warga dan instansi (contoh: ktp, nik, kartu keluarga, npwp, data nasabah, bpjs). Kata ini tidak berdiri sendiri—hanya memicu status relevan jika ditemukan bersamaan dengan indikator aksi (misal: KTP + bocor atau NIK + dijual).

Belum ada kata kunci data sensitif terdaftar.

Objek Aset Digital (Butuh Indikator Aksi)

Fungsi Taktis: Infrastruktur sistem, server, aplikasi, dan database instansi (contoh: website, server, database, aplikasi, rekening, pdns). Wajib berpasangan dengan kata aksi insiden (misal: server + dibobol) agar artikel peluncuran sistem publik normal tidak salah terjaring.

Belum ada kata kunci aset digital terdaftar.
